# 品牌配色 · 完整 App 版

2026-10-23。品牌青由用户确定，App 原始界面是视觉依据。采用 Impeccable colorize 的颜色角色方法，而不是新增多种装饰配色。

| 角色 | 色值 | 使用 |
| --- | --- | --- |
| 品牌 | `#44E0F8` | 桌面产品展示底、下载区、步骤、图标填充 |
| 操作 | `#113F4A` | 主按钮、链接、功能图标轮廓；品牌底上文字 |
| 主文字 | `#202224` | 标题、正文和数字；避免全页文字泛青 |
| 辅助文字 | `#62666A` | 白/浅灰区域说明 |
| 主体 | `#FFFFFF` | 主页面与按钮文字 |
| 分区 | `#F3F5F6` | 流程、FAQ和信息面板 |

派生工具色：浅青 `#E8FBFF`、分隔线 `#D9DFE1`、按钮Hover `#215B68`、焦点 `#00778C`。它们是对应角色的状态，不是独立装饰色板。

首屏白色主体与完整 App 图组成一个区块；手机删除额外套框，让截图占满内容宽度。页面不再用首屏渐变或多种青灰色替代层次。品牌底上说明文字使用深青，保持可读性。

品牌青/白只有1.58:1，因此不用于白底上的小字号文字或独立功能线条。图标以深青轮廓承载识别，青色填充只作辅助，旁有真实文字标签。

本表覆盖上述颜色配对与交互状态，不代表全套无障碍认证或已完成全部色觉模拟。原图内的颜色及文字未重新绘制。
