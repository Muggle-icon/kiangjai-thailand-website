# 品牌配色 · ATS PICO 结构对照版

2026-10-26。保留用户指定的 `#44E0F8` 与 App 深青操作色；采用 Impeccable colorize 的颜色角色方法。布局参考 ATS PICO，不复制其紫红品牌色。以下与 `assets/redesign.css` 当前tokens一致。

| 角色 / token | 色值 | 使用 |
| --- | --- | --- |
| 品牌 / brand | `#44E0F8` | 通栏三入口、下载区、步骤、优势图标填充 |
| 深色前景 / ink | `#113F4A` | 标题、主按钮、链接、图标轮廓、品牌底上文字 |
| 正文 / text | `#202224` | 一般正文和中性数字 |
| 辅助文字 / muted | `#59646A` | 白、浅灰、浅青区域说明 |
| 主体 / paper | `#FFFFFF` | 主页面、完整内容面板、深色按钮文字 |
| 中性分区 / surface | `#F4F7F7` | 安全信息与支持表面 |
| 浅品牌背景 / cyan-soft | `#E8FAFD` | 优势、申请、FAQ连续分区 |
| 分隔线 / line | `#D8E5E8` | 面板、内容与控件边界 |

按钮Hover为 `#215B68`，键盘焦点为 `#00778C`。导航hover/focus用 `#00778C`，selected同色并700字重、无下划线；首页aria-current=location由scrollspy跟随，颜色不单独承担状态。Hero信息区用浅青实色，照片原色完整3:2；44%信息/56%照片分区且文字全部左对齐，无白渐变、蒙版、滤镜或叠字。原图和Logo颜色不重绘。

白色大面板与浅青分区建立整体分组，品牌青集中在明确入口和功能上。深青负责标题与操作，一般正文用中性黑灰，避免把所有文字都当作装饰色。品牌底上说明文字使用深青。

| 前景 | 背景 | 比值 |
| --- | --- | ---: |
| `#202224` | `#FFFFFF` | 15.96:1 |

| `#59646A` | `#E8FAFD` | 5.65:1 |
| `#FFFFFF` | `#113F4A` | 11.45:1 |
| `#113F4A` | `#44E0F8` | 7.23:1 |
| `#FFFFFF` | `#215B68` | 7.61:1 |
| `#00778C` | `#FFFFFF` | 5.23:1 |
| `#00778C` | `#44E0F8` | 3.30:1 |

品牌青/白只有1.58:1，因此品牌青不用于白底的小字号文字或唯一功能线条。图标以深青轮廓承载识别，青色填充辅助，旁有真实文字标签。
