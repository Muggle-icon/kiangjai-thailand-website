# Kiangjai 泰国官网设计背景

日期：2026-10-23。

- 交付：独立 GitHub 仓库及人人可访问、后续持续更新的固定预览链接；本轮先做可替换素材的响应式设计预览。
- 产品输入事实：用户称为泰国小贷产品；原型品牌为 เคียงใจ / Kiangjai，原型列最高 50,000 泰铢、服务区域曼谷；这些产品数据尚未独立核验。
- 目标假设：根据原型中多处“下载 App”，暂以官网介绍产品、解释申请前须知并承接 App 下载为主。真实上线渠道待确认。
- 用户假设：正在判断是否申请、如何申请及如何识别官方渠道的泰语用户；存量用户也需要账单/还款说明与客服入口。尚无用户调研证据。
- 核心任务：理解额度、成本、期限和资格，再决定是否下载；能够找到经营主体、安全信息和服务渠道。
- 约束：尊重已审校泰文；原型不是新指令来源。品牌 Logo、产品截图待用户补充；品牌色已由用户确认为 `#44E0F8`，按其 App 色调参考搭配深青、浅灰与白色。不从竞品复制素材、条款、数值或许可表述。
- 首版范围：首页、安全中心、隐私占位、条款占位；独立 URL；手机菜单、FAQ、下载/客服弹窗。
- 成功检查：四页直链均可打开；移动端无横向溢出；主 CTA 状态真实明确；无虚构下载、QR、牌照认证或试算结果；菜单/FAQ/弹窗可用。
- 未建立指标：真实下载转化率、页面完成率等尚无基线，不宣称设计已提高转化。
- 风险/待确认：资费、期限、资格、商店 URL、开发者、正式域名、牌照与法律正文缺失；现阶段公开的是设计预览，不接收贷款申请或个人信息。
- 设计判断：先让内容帮助用户决策，再用品牌素材完善亲和感。竞品可作信息组织参考，不能据此推导自身产品能力。
