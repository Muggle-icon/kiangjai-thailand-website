# 泰国小贷官网竞品观察

核查日期：2026-10-23。以下是官网页面内容与设计观察，不能替代用户自身的产品确认或牌照法律审核。网站自行宣称“合法/受监管”是页面事实，不等同于本次已完成牌照核验。未提交申请、回访或联系表单。

## 最重要的判断

【设计判断】可以借鉴 ATS PICO 的“亲和人物 + 明确产品信息 + 申请路径”，但不能据此决定我们也应采用其额度、利率、地域、门店或双申请模式。ATS 的省级 PICO，和 FINNIX / MoneyThunder / Rabbit Cash 所展示的 nano、personal、循环额度产品有显著区别。

## 页面事实

### ATS PICO

- 官网：https://www.atspico.co.th/home
- 页面顺序：人物 Hero / 申请 CTA → 产品/申请/FAQ 快捷入口 → 四项产品卖点 → 月供试算 → App 或网站申请、另提供回访表单 → 联系/分公司 LINE / 门店 → 下载 App / 隐私。
- 首页列最高 100,000 泰铢、最长 24 月、28%–36% 实际年利率；试算有担保/无担保选项。
- 明确存在网站申请 https://onlinelending.atspico.co.th 和 App 下载 https://onelink.atspico.co.th 两个入口，以及收集姓名、电话、月收入、省份、意向金额的回访表。
- 联系页 https://www.atspico.co.th/contact-us 有法人名称、地址、表单，首页有 Bangkok / Samut Sakhon 两个 LINE 与门店查找。仅本次主页/联系页读取中没有辨认出独立投诉链接，不能推断站点完全没有。
- 【视觉核实】已看首屏：白/奶油色底、紫红强调，左侧普通消费者、右侧服务人员，居中泰文标题与申请按钮。右下 App QR 浮层与底部 cookie 条同时显示。
- 【设计判断】生活人物有助于表达“附近可信赖的朋友”；浮动 QR + cookie 两层遮挡不宜原样套入移动端。

### FINNIX

- 官网：https://www.finnix.co/
- 页面顺序：最快 5 秒及监管自述 → 产品卖点 → 申请资格 → 利息/还款计算 → 多产品信息与计算 → 用户评价 → FAQ → 新闻/金融知识 → 下载与联系。
- 申请与下载链接均导向 https://go.finnix.co/，网站目标明显包含 App 获客。
- nano 产品区展示最高 100,000 泰铢、2.75% 月利率及 33% 年利率；资格为泰籍、20–60 岁、最低月收入 8,000 泰铢；证件与银行流水要求可见。
- 官网还展示 personal 产品，不能把首页所有金额、利率、期限混成同一种产品。
- 首页有公司名称、电话、邮箱、地址。仅本次首页读取未辨认出独立投诉入口。
- 【推测】“快、可申请资格、如何还款”是其帮助用户决定是否下载的主要信息；效果没有转化数据支持。
- 【证据边界】只做官方页面文本核查，未完成视觉截图核实。

### MoneyThunder

- 官网：https://www.money-thunder.com/ （从 ABACUS 官方产品页 https://www.abacusdigital.com/product 的 Visit MoneyThunder Website 链接确认域名）。
- 页面顺序：最快 10 分钟及申请 CTA → 线上贷款定义/适用人群 → 产品卖点与监管查询链接 → 现金贷款/数字现金卡两种产品 → 试算入口 → 社会成效/奖项 → 促销/金融知识 → FAQ → 经营主体/下载/联络/公告。
- 现金贷款产品卡注明 nano，常规年利率 33%、最高 100,000 泰铢；数字现金卡产品卡注明 personal，常规年利率 25%、有受收入条件限定的额度。它对不同产品的披露区分值得参考。
- 顶部和底部申请均指向 App OneLink；首页有 BOT 监管查询站的直接链接。
- 首页底部有法人、注册地址、LINE、邮箱、客服时间、利率/费用公告、产品投诉报告和反腐举报入口。
- FAQ https://www.money-thunder.com/faq 按申请、贷款信息、合同/提款、计息、还款等主题组织。
- 【设计判断】值得借鉴按产品分别披露与从官网直接进入真实验证渠道；多产品、奖项、营销内容较多，不适合一个尚未准备这些内容的品牌机械铺满首页。
- 【证据边界】只做官方页面文本核查，未完成视觉截图核实。

### Rabbit Cash

- 官网：https://www.rabbitcash.co.th/
- 首页为多产品门户：促销与产品 → 个人/企业入口 → 五问题产品推荐 → 下载/联络/披露链接。不是纯单产品落地页。
- 产品详情：https://www.rabbitcash.co.th/personal-loan/loan-revolving 有页内导航：卖点 / 计算 / 资格与文件 / 申请方式 / FAQ。
- 详情页列最高 100,000 泰铢、33% 年利率、无申请费、循环额度与最低还款；明确试算仅为预估值。资格为泰籍、20–65 岁、月收入至少 8,000 泰铢，需身份证和过去 6 个月 E-Statement。
- 产品披露表、利率公告与计息说明都有显式链接；申请路径为 App Store / Google Play。
- 联系页 https://www.rabbitcash.co.th/contact 有电话、时间、LINE、邮箱、地址；表单主题含服务投诉和申请问题。
- 【设计判断】详情页的页内导航适用于长产品说明；五问推荐适合多产品/确有分流逻辑的业务，用户若只有一个产品则增加步骤。
- 【证据边界】只做官方页面文本核查，未完成视觉截图核实。

## 对当前站点可执行的建议

1. 【设计判断】第一版首页按用户决策顺序组织：这是什么/谁提供 → 核心额度、成本、期限与地区条件 → 我是否适合 → 怎么申请 → 还款/费用与 FAQ → 联系和投诉。可在首屏放主 CTA，但不能让用户只能先下载才知道成本。
2. 【待确认】主路径究竟是 App 下载、网页申请、还是客服回访。可先占位；不把未上线下载按钮连到别人的商店，也不做假提交成功。
3. 【设计判断】经营主体、联系渠道、完整费率及政策入口是信任的重要信息；不要用未经核实的徽章、监管 logo、客户数量或用户评价替代。
4. 【待确认】若做还款计算器，需要产品确认计息、还款规则、费用与公式；在确认前用说明型占位，不显示貌似准确的月供。
5. 【设计判断】移动端底部只保留一个主行动；桌面端可用下载 QR，移动端应直接跳正确 App 商店/深链。
6. 【图片清单】首轮只必需：品牌 SVG/透明 PNG、App 图标、App 首页、额度/申请页面、还款/账单页，及用户有授权的泰国生活人物图（可先占位）。监管或合作方标志须有真实关系与授权依据；不复制竞品图片。
