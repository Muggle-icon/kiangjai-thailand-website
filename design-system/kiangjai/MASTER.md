# Kiangjai 网站设计规则

版本：2026-10-23 App 视觉统一版。适用首页、安全中心、隐私、条款与共享组件。

## 优先级

1. 用户批准的原型业务内容及最新视觉要求。
2. 用户 Logo、品牌色、App 原始界面。
3. 本项目规则；UI UX Pro Max 提供通用布局、可访问性、交互检查依据。

技能搜索第一次返回通用 SaaS 推荐，已舍弃；第二次以 banking finance 缩窄，采用其清晰层级与可访问性原则。数据库没有精确匹配本项目的泰国小贷视觉，因此没有照搬推荐色板、字体或银行门户布局。具体数值是本项目决策。

## 布局

| 项目 | 桌面 | 手机 ≤760px |
| --- | --- | --- |
| 内容最大宽度 | 1200px | 随视口 |
| 内容外边距 | 至少40px，超宽居中 | 24px |
| 一级标题 | 48px / 1.4 | 36px / 1.45 |
| 模块标题 | 32px / 1.55 | 28px / 1.55 |
| 正文 | 16px / 1.85 | 16px / 1.85 |
| 辅助/法律说明 | 14px / 12px | 14px / 12px |
| 分区上下留白 | 80px | 56px |
| 容器内边距 | 32px | 24px |
| 主操作高度 | ≥56px | ≥56px |

- 间距阶梯：8、16、24、32、40、48、56、80px；细线和图像描边按用途单独定义。
- Logo、首屏、模块标题、正文容器、页尾共用同一内容轴。不要用100vw计算页尾边距，避免滚动条偏差。
- 标题和正文左对齐；移动快捷导航、步骤数字、图标及按钮内部可居中。卡片有明确内部24/32px缩进，不强求卡片内文与页面外边缘重合。
- Hero 信息紧邻：品牌主张→额度→优势→下载→原说明。手机随后显示 App 主界面。
- 优势为开放式三列/手机连续行；申请为步骤列表与真实截图；公司/安全为完整信息区；FAQ为连续列表。

## 颜色与形状

- 品牌：`#44E0F8`；主操作/标题：`#113F4A`；正文：`#202224`。
- 辅助文字：`#516D76`；白色：`#FFFFFF`；浅灰：`#F1F5F6`；浅青：`#E9FAFC`；分隔线：`#DCE6E9`。
- 不在青色按钮上使用白色小字。按钮继承 App 深青胶囊形，白色文字。
- 面板圆角32px/手机24px；截图统一圆角和白边；禁用多种无意义阴影、角度和装饰箭头。
- Hero 可使用与 App 相近的简单浅青到浅灰过渡，其他模块用平面分区。

## 字体与图片

- 自托管 Noto Sans Thai，保留自然泰文断行；不得对正文使用 break-all 或裁掉变音符号。
- 仅使用同一 Lucide 图标体系。方向符号用于实际操作时才可出现。
- 使用首页、选期、扫码还款三张用户原图；保持原图像素，不改数字、文字或账户状态。
- 首页图采用顶部预览，流程两图完整展示。图片链接打开完整原图；不把截图内的按钮做成虚假的网页控件。
- 当前页面不加载人物素材。其他状态图不强行堆叠，避免还款/逾期等不同账户状态混成同一个营销承诺。

## 交互与验收

- 可点击控件具备 hover、focus-visible、active 反馈；主要触控目标≥44px，主CTA≥56px。
- 真实 button、anchor、dialog；菜单与FAQ有展开状态，弹窗可Escape关闭并恢复焦点。
- 支持 prefers-reduced-motion，不增加自动播放和无意义入场动画。
- 普通文字对比度目标≥4.5:1。检查1440、390、360及中间宽度，没有横向溢出或泰文重叠。
- 原型181条泰语与业务入口不变；不添加虚构牌照、人数、审批时长、评价或真实外部链接。
- 交付前必须实际浏览、保存截图、核查页面和内容；技能安装不等于设计验收通过。
