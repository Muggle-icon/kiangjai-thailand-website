# Kiangjai网站设计规则

版本：2026-10-26居中导航与左对齐Hero版。适用四页和共享组件；规则数值为代码约束，实际通过情况以本轮QA为准。

## 优先级

用户批准的原型及最新要求优先；其次是指定ATS PICO的结构与比例、自有品牌素材和本项目规则。技能仅辅助，不复制竞品图片、文案或业务条件。新DOCX差异见 [内部审查](../../docs/product-requirements-review.md)，不直接把中文替换为泰语。

## 完整首屏和导航

- 照片为1536×1024的 `market-life.jpg`，以3:2自然比例完整显示。禁止照片裁切、叠字、渐变、蒙版、滤镜和透明人物；信息与照片各有独立区域。
- 桌面Hero为信息44%/照片56%，撤销25%窄栏。标题、金额、概述、CTA、说明全部左对齐；h1和额度800字重。Hero设inline-size容器，左内边距为max(gutter,(100cqw−1120px)/2)，对齐正文轴线；不写死Hero高度。
- 手机和761–900px先信息后完整照片；信息主张与额度分列但各自左对齐，利益点、CTA、说明跨列且左对齐。自然高度，不复用旧25/75时的高度结论。
- 页头用用户原始完整 `logo-wordmark.png`（368×128），桌面宽164px、手机128px/窄屏120px；不能裁掉名称。页尾横版Logo及App图标不变。旧symbol仅存档。
- 桌面页头88px，176px/minmax(0,1fr)/176px网格等宽两侧槽，导航居中；≤1040px折叠页头72px、手机64px。桌面sticky配112px锚点偏移；手机relative配24px偏移。
- 导航hover/focus变为#00778C，selected相同颜色并加粗700，无下划线。首页scrollspy用aria-current=location，安全页用page；需实测滚动、hash直达、回滚首屏及resize，不能只凭代码判定通过。

## 颜色、字体与素材

- CSS tokens为准：品牌#44E0F8、深青#113F4A、正文#202224、辅助#59646A、白#FFFFFF、浅灰#F4F7F7、浅青#E8FAFD、边线#D8E5E8。见 [brand-colors](../../design/brand-colors.md)。
- Hero信息区用浅青实色，照片原色；品牌青用于三入口、下载、步骤、图标填充，浅青衬白色大面板。无照片可读性渐变。
- 标题、操作、链接、图标轮廓深青，正文中性黑灰；深青胶囊按钮白字，不在品牌青上放白色小字。
- 所有可编辑文字统一自托管Noto Sans Thai，保留SIL OFL。自然泰文断行，不用break-all或裁变音符。
- 四优势使用Phosphor Duotone手机、银行、二维码、警示盾牌；系统控件用Lucide。禁止无意义箭头、波浪和光球。
- 三张原始App PNG不改数字、文字、状态，不据此扩写条款。截图内按钮不是网页控件。
- 完整市场照片不是客户证言或真实借款案例；透明 `merchant-cutout.png`仅历史存档。

## 验收

控件具备hover/focus-visible/active；点击目标≥44px。一般按钮56px，Hero52px，页头48px/手机44px。使用真实button/anchor/dialog，弹窗Esc关闭及焦点恢复，支持reduced-motion。

实查1440、390、360及中间宽度：无页面溢出、泰语重叠或孤字标题，照片与App图完整，菜单/锚点、画廊、FAQ、弹窗可用。普通正文对比目标≥4.5:1、功能图形≥3:1。

181条文案及四页原入口保持，下载both/官方渠道complete仍为已审演示，不虚构生产配置、法律正文、资质或链接。发布前真实浏览、截图并核查内容；技能安装不能代替验收。

### 已知的次要比例限制

Hero保持完整照片而不强行cover裁切。当两栏信息自然高度高于照片自然高度时，照片上下可能出现浅青留白。本轮主代理测量1200px时约各1.5px、1040px时约各65px；这是完整图片与文字高度的折中，不属于图片缺失或裁切。后续若调整仅处理该中间断点，不为此重写整站，仍需检查泰语及CTA完整。
